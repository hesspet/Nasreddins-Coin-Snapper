# Nasreddin's Coin Snapper

Ich verfolge hier eine Idee mit Smartphone, Smartwatch und ein paar Microcontrollern eine sehr spezielle Münzroutine zum Zaubern zu entwerfen.

Dieses Repository ist aktuell nur ein Sammelbecken für Fragmente und Ideen, inkl. einiger Machbarkeitsstudien. Wie z.b. kann man ein ESP32 Kamera nutzen eine Münze in der Hand aufzunehmen... :-)
